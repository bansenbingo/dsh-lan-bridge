# 0.1.4 更新说明（macOS）

## 这次改了什么

0.1.4 是 0.1.3 的补丁：功能没变，只把 Fork 失败时的报错改成看得懂的话。下面第 2-5 条是 0.1.3 的内容，从更早版本升上来的话也一并生效。

1. **修：Fork 失败时不再是「HTTP 500」**
   对一条空对话（对端只同步过来一个空壳，没有任何消息）点 Fork，以前只弹「HTTP 500」，现在明确告诉你「这条会话没有可 fork 的内容」，按钮也会先置灰。如果选好的工作区刚好被删了，会提示「目标工作区不存在了，刷新后重新选一个」，而不是悄悄 fork 到别的工作区。

2. **修：0.1.2 会让面板整个渲染失败**
   升级到 0.1.2 后打开面板，只看到「局域网面板渲染失败」和一串堆栈（首行 `think is not defined`）。这是 0.1.2 的缺陷，0.1.3 已修，装完重开 DSH 就好。

3. **修：Markdown 排版挤成一团**
   行距、字重之前被错误地补了 `px`（生成 `line-height:1.62px`），正文几乎叠在一起。现在无单位数值不再加 `px`；顺带修好嵌套列表结构、表格横向滚动与列对齐、首个标题多余的上边距。

4. **新：把任意一条对话 Fork 到本机工作区**
   面板「对话」页右侧选一个本机工作区、点 **Fork**，会把当前这条对话写成一份新的 DSH 会话，并挂进那个工作区 —— 刷新页面就能在侧栏看到，点开接着聊。本机的对话和别的电脑同步过来的对话都能 fork；只搬用户消息与助手正文，原会话一个字节都不会被改。

5. **思考链可以一键折叠**（0.1.2 引入，仍然可用）
   正文区顶部多了「展开全部思考 / 折叠全部思考」按钮，一次控制整段对话的所有思考链；单条的「思考链」仍然可以单独点开。

## 怎么装

```bash
unzip -o dsh-lan-bridge-0.1.4-macos.zip -d ~/Downloads/lan-bridge
bash ~/Downloads/lan-bridge/install-macos.sh
```

脚本只做三件事：备份旧版本 → 覆盖插件文件 → 语法校验。
它**不会碰** `~/.dsh/lan-bridge/config.json`（角色、令牌、地址都在那里），所以装完不用重新配对。

## 装完必须做的一步

**完全退出 DSH（Command+Q）再重新打开**，不是刷新页面。
host 半的插件在启动时加载，不退出不会换成新代码。

启动后：侧边栏点局域网面板 → 打开任意一条同步过来的对话，就能看到 Markdown 排版、折叠按钮；右侧工具条可以把它 fork 到本机工作区。
