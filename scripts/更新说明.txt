# 0.1.2 更新说明（macOS）

## 这次改了什么

1. **同步过来的正文会按 Markdown 显示了**
   标题、代码块、行内代码、粗体、列表、表格、引用、链接都会被正确排版，不再是一坨纯文本。

2. **思考链可以一键折叠**
   正文区顶部多了「展开全部思考 / 折叠全部思考」按钮，一次控制整段对话的所有思考链；单条的「思考链」仍然可以单独点开。

3. 顺带修了一个样式单位的毛病（`font-size` 少了 `px`，在浏览器里等于没生效）。

## 怎么装

```bash
unzip -o dsh-lan-bridge-0.1.2-macos.zip -d ~/Downloads/lan-bridge
bash ~/Downloads/lan-bridge/install-macos.sh
```

脚本只做三件事：备份旧版本 → 覆盖插件文件 → 语法校验。
它**不会碰** `~/.dsh/lan-bridge/config.json`（角色、令牌、地址都在那里），所以装完不用重新配对。

## 装完必须做的一步

**完全退出 DSH（Command+Q）再重新打开**，不是刷新页面。
host 半的插件在启动时加载，不退出不会换成新代码。

启动后：侧边栏点局域网面板 → 打开任意一条同步过来的对话，就能看到 Markdown 排版和折叠按钮。
